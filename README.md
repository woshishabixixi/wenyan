# 文言文生词 · 间隔复习

一个照扇贝单词的手感做的文言文生词复习工具：**先只看词，回想释义，点一下才展开，然后三档评分**，
间隔由遗忘曲线算法安排 —— 认识就拉长，模糊就小步走，不认识就打回 10 分钟重来。
所有数据只存在你自己的手机上，不需要注册、不联网、不上传。

- 可安装：iPhone Safari / 安卓 Chrome 里「添加到主屏幕」，打开就是全屏 App
- 可离线：Service Worker 缓存了全部文件，飞行模式也能背
- 内置 302 条文言文高频词（818 个义项，96% 带课文例句与出处），也可自己加词、批量导入、删除已会的词

## 一、先在电脑上试一下

需要 Node.js（本机已有）。在这个目录里执行：

```bash
node tools/serve.mjs
```

然后浏览器打开 <http://127.0.0.1:8787> 。
换端口：`PORT=9000 node tools/serve.mjs`（PowerShell 里用 `$env:PORT=9000; node tools/serve.mjs`）。

> 直接双击 `index.html`（file:// 方式）**不行**：浏览器会禁止本地文件读写 IndexedDB 和加载词库。
> 必须用上面的本地服务器，或者部署到网上（下一步）。

## 二、部署到免费托管（约 3 分钟）

整个 `wenyan-srs` 目录就是成品，**没有任何构建步骤**，把目录里的文件原样上传即可。
注意：所有链接都是相对路径，所以**必须把目录内容放在网站根目录**，不要多套一层文件夹。

### 方式 A：GitHub Pages（推荐）

1. 注册/登录 GitHub，点右上角 **+ → New repository**，名字随意（例如 `wenyan`），选 **Public**，创建。
2. 进入仓库，点 **Add file → Upload files**，把 `wenyan-srs` 里的这些内容全部拖进去：
   `index.html`、`styles.css`、`app.js`、`srs.js`、`db.js`、`manifest.webmanifest`、`sw.js`、
   `data/`（整个文件夹）、`icons/`（整个文件夹）。点 **Commit changes**。
3. 仓库 **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 **main**、目录选 **/(root)** → **Save**。
4. 等 1 分钟左右，页面顶部会出现网址：`https://<你的用户名>.github.io/wenyan/`
5. 手机浏览器打开这个网址。

### 方式 B：Cloudflare Pages

登录 Cloudflare → **Workers & Pages → Create → Pages → Upload assets** → 把整个目录拖进去 → 部署，
得到一个 `https://xxx.pages.dev` 的网址。

### 方式 C：你自己的服务器

把目录丢到任意 HTTPS 静态目录即可（Nginx/Apache 都行）。**必须是 HTTPS**，否则手机上装不了、也离线不了。

## 四、怎么用

底部四个标签：

| 标签 | 作用 |
|---|---|
| **复习** | 今天要背的卡。只显示词和拼音 → 点一下卡片任意空白处展开释义、例句、出处 → 底部三个按钮才亮 |
| **已掌握** | 你点过「太简单」或「删除」的词都存在这里，**不参与推送**，随时可以「恢复」回队列 |
| **词库** | 搜索 / 新增 / 编辑 / 删除；底部可批量粘贴导入。编辑时**一条词可以挂多条解释**，每条能单独勾「不常考」 |
| **设置** | 每日新词上限、模糊/不认识的间隔张数、导出 JSON、导入备份、重置、统计 |

**「模糊」和「不认识」的卡会在同一轮里隔几张再出现**（不是立刻重复，也不是直接推到明天），
直到你给它评一次「认识」才算过。间隔张数在「设置 → 不认识的词，隔几张再出现」里调，
范围 3–10，默认 4，**代码里强制不低于 3**（填 1 会自动变回 3）。这样忘记的词当天能补好几遍。

三档按钮的含义：

- **不认识**：这张卡打回 10 分钟后再来，已学会的卡会计一次「遗忘」并降低它的易度因子
- **模糊**：间隔只乘以 1.2 倍，同时降低易度因子（半熟的词会被压住反复打）
- **认识**：间隔乘以易度因子（2.5 起，最高 3.0），最长 365 天

新卡第一次评「认识」→ 1 天后；再评「认识」→ 毕业，3 天后；之后按易度因子翻倍式增长。
每天引入多少张新卡由「设置 → 每日新词上限」控制（默认 20），学过的旧卡到点就会自动排进队列，不受此限。

### 一条词挂多条解释 / 标记「少考」

内置词库现在 326 个词、957 条解释（平均每词 2.94 条），其中 36 条不常考的义项被标了「少考」——
卡片上会显示成 `动 · 少考 · 通「薆」，隐蔽；隐藏`，一眼能看出这条可以先放一边。

你自己加词或改词时：

1. 词库 → 点某条的「编辑」
2. 表单里每条解释是独立一块，点 **「+ 再加一条解释」** 就能挂第二、第三条
3. 觉得哪条不常考，勾上 **「不常考」**（释义前会显示「少考」标记）
4. 「删除这条」可以移除多余的解释

批量粘贴里也能标：**释义前面加一个 `*`** 就表示少考，例如 `薆 *通「薆」，隐蔽`。

### 批量粘贴导入格式

每行一条，三种写法都认，重复的词自动跳过（会提示「导入 N 条，跳过 M 条」）：

```
# 1) 最省事：一行一个词，释义之后再补
邂逅
囹圄

# 2) 词 + 拼音 + 释义（拼音可省，多音节用空格分开）
囹圄 líng yǔ 监狱
龃龉 上下牙齿不齐，比喻意见不合

# 3) 完整格式，竖线分隔，后几项可省
走|zǒu|动|跑；逃跑|弃甲曳兵而走|《寡人之于国也》
```

从 Word / 微信里直接复制一列词粘进来就行，不需要整理成表格。

## 五、备份与换手机

数据存在这台手机浏览器的 IndexedDB 里，**清浏览器数据/卸载会丢**。换机步骤：

1. 旧手机：设置 → **导出 JSON**，得到一个 `wenyan-backup-YYYYMMDD.json`
2. 把文件传到新手机（微信文件传输助手 / 邮件 / 网盘都行）
3. 新手机打开同一个网址 → 设置 → **导入备份** → 选这个文件 → 确认覆盖

导入会整体覆盖，导入前会二次确认。

## 六、更新版本

把新文件重新上传覆盖服务器上的旧文件即可。**联网状态下刷新一次就生效**（Service Worker 现在是网络优先、
断网才回退缓存）；断网时会用上次缓存的版本，属于正常现象。

### 词库怎么更新

词库文件里带一个版本号（`data/deck.builtin.json` 的 `version`）。新版本部署后打开 App，
它会自动做**增量合并**：新增没见过的词条、补充/修正已有词条的释义，
**你自己的复习进度（间隔、到期时间、已掌握状态）完全不受影响**，并提示「词库已更新：新增 X 条 · 补充释义 Y 条」。
自己手动加的词条（origin 为 custom）不会被覆盖。

## 八、关于内置词库

内容覆盖：高中文言文高频实词、18 个常见虚词（按用法分义项）、通假字、古今异义、词类活用。
释义与例句按通行教材整理。**词条内容可以在「词库」页直接编辑**——如果你发现某条释义不合你的课本口径，
改掉就行，不必等我改。

算法说明：不是严格的 FSRS，而是 SM-2 变体——学习阶梯（10 分钟 / 1 天）＋ 易度因子（1.3–3.0）＋
间隔上限 365 天。它和扇贝的调度思路一致：**会背的往后推，记不住的往前压**。
